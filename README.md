# Business Analytics with Power BI

Power BI reports and write-ups from the Business Analytics course (BCA Semester V, Alliance University). Each folder holds one report (PDF) together with its Power BI file (.pbix).

## Projects

| Folder | Topic | Tools |
|---|---|---|
| [Experiment-1_Importing-Data_AdventureWorks](Experiment-1_Importing-Data_AdventureWorks) | Importing AdventureWorks sales, customer and product CSVs, building a data model and a one-page dashboard | Power BI, Power Query |
| [Superstore_Sales-and-Profit](Superstore_Sales-and-Profit) | Sales and profit dashboard on the Sample Superstore dataset | Power BI, Power Query |
| [Experiment-3_Building-Dashboard_AdventureWorks](Experiment-3_Building-Dashboard_AdventureWorks) | Retail dashboard with KPI cards and a Total Sales measure | Power BI, Power Query, DAX |
| [Experiment-4_Data-Cleaning_Power-Query](Experiment-4_Data-Cleaning_Power-Query) | Cleaning a deliberately dirty cafe sales dataset | Power Query |
| [Experiment-5_Customer-Analysis-Dashboard](Experiment-5_Customer-Analysis-Dashboard) | Customer analysis: categories, payment methods, monthly revenue, customer concentration | Power BI, DAX |
| [Experiment-6_Sorting-and-Filtering](Experiment-6_Sorting-and-Filtering) | Sorting and filtering a 300-transaction sales dataset to find high-value and loss-making items | Power BI, Power Query, DAX |

## How to open the reports

1. Install Power BI Desktop (Windows).
2. Open the .pbix file in a folder to explore the model and visuals, or read the PDF in the same folder for the full write-up.

## Notes

- The raw source datasets (CSV/Excel) are not stored in this repository as separate files. Each folder README names the source dataset.
- These are academic coursework projects.
