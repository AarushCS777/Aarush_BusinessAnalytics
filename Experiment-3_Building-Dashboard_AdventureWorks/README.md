# Experiment 3: Building a Dashboard (AdventureWorks)

**Files:** `BuildingDashboard_Aarush.pdf` (report), `BuildingDashboard.pbix` (Power BI file)

## Business question
How can sales, customer and product data be consolidated into one dashboard that shows total sales, order quantity, customer distribution and product performance?

## Data
Retail order data with customer and product information. The .pbix model uses AdventureWorks tables. Fields used include OrderDate, OrderQuantity, ProductPrice, ProductName, CustomerKey and Gender.

## What was done
- Imported and cleaned the tables in Power Query (duplicates, blanks, missing values, column names, data types).
- Built a data model with relationships between the sales, customer and product tables.
- Created a Total Sales measure: OrderQuantity x ProductPrice.
- Designed an interactive dashboard with KPI cards, charts and slicers.
